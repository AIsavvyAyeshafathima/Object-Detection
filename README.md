# Object-Detection
Initial Raw AI Model:
In this project, we utilized the YOLOS (tiny-sized) AI model from HuggingFace, which is available at HuggingFace. This model is designed for object detection tasks, leveraging a transformer-based architecture to identify and locate objects within an image. The YOLOS model, particularly its tiny variant, is known for its efficiency in terms of computational resources while maintaining satisfactory performance in identifying various objects.
Limitations of the Model:
Despite the efficiency of the YOLOS (tiny-sized) model, it exhibits several limitations. Firstly, the model struggles with identifying objects present in varying magnitudes, such as multiple cars on a highway. This limitation suggests a need for improvement in scenarios involving high object density and varying object sizes. Secondly, the model lacks the capability to identify colors within an image, a critical feature for applications requiring color-specific information. Lastly, the model cannot recognize text in photos, which restricts its use in scenarios where textual data is significant, such as document analysis or scene text detection.
Feature Added: Dominant Color Identification:
To address the color identification limitation, we incorporated a feature that identifies dominant colors in an image using K-means clustering. K-means clustering is a method that groups pixels into k clusters based on their color values. By applying this method, we can extract the most prominent colors in the image. For this project, we set k to 5, meaning the image's colors are grouped into five dominant clusters. The output includes both the RGB matrix of the k dominant colors and a visual representation of the color palette along with their respective magnitudes in percentage.

Conclusion
The YOLOS (tiny-sized) AI model demonstrated strong performance in identifying several objects, including people, birds, animals, benches, wine glasses, and cars. These results indicate that the model is well-suited for general object detection tasks involving common items and scenarios. However, the model's performance was suboptimal for specific objects and conditions. It struggled with identifying trees, objects at a distance, and yellow color when present in small traces. Additionally, it had difficulty recognizing food items such as fruits and meat, as well as small insects and flies.
In summary, while the YOLOS (tiny-sized) AI model is effective for a range of general object detection tasks, its limitations highlight the need for further enhancement. Incorporating the ability to identify dominant colors using K-means clustering provided a valuable extension to its capabilities, addressing the gap in color recognition. Future improvements could focus on enhancing the model's ability to detect objects across varying magnitudes and incorporating text recognition capabilities to broaden its application scope.
